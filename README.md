# Kenntnisprüfung RLP — Lernatlas

Rheinland-Pfalz-ის Kenntnisprüfung-ისთვის (Approbation) მოსამზადებელი ინტერაქტიული სასწავლო მასალა.

**გახსნა:** GitHub Pages-ის ბმული ამ რეპოზიტორიის „About“ განყოფილებაშია (`https://<user>.github.io/<repo>/`).

## როგორ ინახება პროგრესი
- „ნასწავლია“ მონიშვნები და ბოლოს გახსნილი თემა ინახება **თითოეული ადამიანის საკუთარ ბრაუზერში** (localStorage). ყველას თავისი პროგრესი აქვს და ერთმანეთს არ ეხება.
- საიტის განახლება პროგრესს **არ შლის**.
- პროგრესი იშლება მხოლოდ მაშინ, თუ ბრაუზერის მონაცემებს წაშლი, პირად (incognito) რეჟიმში მუშაობ ან მოწყობილობას გამოცვლი. ამიტომ სარჩევში დროდადრო გამოიყენე „💾 პროგრესის შენახვა“ — ფაილი ან კოდი.
- **iPhone:** Safari → „გაზიარება“ → „Add to Home Screen“. მთავარ ეკრანზე დამატებული საიტის მონაცემებს Safari 7 დღის უმოქმედობის შემდეგ აღარ შლის.
- **Android:** Chrome → მენიუ → „Install app“ / „Add to Home screen“.
